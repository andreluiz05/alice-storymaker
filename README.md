# ✨ Alice Storymaker

> **Fotografia autoral com sensibilidade, elegância e compromisso com a sua história.**

Um portfólio web de alta performance desenvolvido para destacar o trabalho fotográfico de **Alice Storymaker**. O projeto foi construído com foco em **Design Premium (High-End Visual Design)**, performance e usabilidade impecável em qualquer dispositivo (Mobile-First).

---

## 📸 Visão Geral do Projeto

Este site atua como um cartão de visitas digital de alto padrão. O design foge de templates engessados (nada de visual padrão de WordPress ou Bootstrap), utilizando uma paleta de cores curada, tipografia elegante e micro-interações que criam uma experiência de navegação imersiva e sofisticada.

### 🎨 Identidade Visual (Design Tokens)
- **Fundo Principal (Bege):** `#F4EFEA`
- **Fundo Secundário (Rosado/Lilás):** `#EBDCE7`
- **Títulos (Vinho/Bordô):** `#5A182F`
- **Texto Corporal (Marrom/Cinza):** `#352B2D`
- **Detalhes e Acentos (Dourado/Rosa):** `#DBA83D` / `#DD6C98`

### 🔤 Tipografia Premium
- **Oswald:** Para títulos de impacto.
- **Playfair Display (Itálico):** Para detalhes editoriais e toques artísticos.
- **Poppins:** Para textos corridos e legibilidade perfeita.

---

## 🚀 Tecnologias e Técnicas Utilizadas

- **HTML5 Semântico:** Estrutura limpa, acessível e otimizada para SEO.
- **Vanilla CSS3 (Sem Frameworks):** Estilização 100% customizada para garantir exclusividade.
- **CSS Grid & Flexbox Avançados:** Layouts dinâmicos e assimétricos (especialmente na galeria de portfólio).
- **Tipografia Fluida (`clamp()`):** Os textos crescem e diminuem organicamente dependendo do tamanho da tela.
- **Animações "Magic" (Cubic-Bezier):** Transições extremamente suaves de botões, menus e revelação de elementos que simulam a leveza do sistema iOS.
- **Imagens WebP:** Foco máximo em performance e carregamento rápido.

---

## 📱 Responsividade (Mobile-First)

O projeto foi inteiramente planejado para telas de todos os tamanhos:
- **Mobile (Smartphones):** Leitura confortável, menus colapsáveis suaves e CTAs (botões) expandidos em 100% da tela para facilitar o toque (Lei de Fitts).
- **Tablets (iPads):** Grades de 2 colunas adaptáveis, garantindo que o texto nunca sobreponha as imagens.
- **Desktop (Monitores Grandes):** Aproveitamento de telas largas com alinhamentos centralizados e sombras expandidas.
